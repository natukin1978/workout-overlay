# 筋トレオーバーレイ

WelcomeカウントBOT と連携して、配信画面上にリアルタイムで筋トレの「総数」と「未消化数」を表示する、配信画面用オーバーレイ（画面表示パーツ）です。

リスナーさんが来訪したときの未消化カウントアップや、配信者さんの音声カウントダウンに合わせて、画面内の数字がサクサク、お洒落に動きます。

## 主な機能

- リアルタイム数値同期

- - バックエンド（WelcomeカウントBOT）と連動し、ページをリロードすることなく一瞬で画面の数値が更新されます。

- 音声モード視覚化

- - 配信者が「筋トレ開始」を発話して音声認識モードに入ると、画面の表示スタイルが切り替わり、現在カウント待ち状態であることがリスナーさんにも一目で伝わります。

- 効果音（SE）通知機能

- - カウントが追加されたときや、筋トレを消化したときに、配信の邪魔にならない心地よい効果音が鳴ります。

## 使い方（OBSへの配置方法）

本ツールは `WelcomeカウントBOT` が起動している状態で使用します。

### OBS Studio に配置する場合

1. OBSの「ソース」パネルにある `+` ボタンをクリックし、「ブラウザ」を選択します。
2. URLの欄に以下のURLを入力します。

```
https://natukin1978.github.io/workout-overlay/?vol=33
```

vol=33 の部分は効果音の音量（ボリューム）です。0（消音）から 100（最大）までお好みに合わせて調整してください。

サイズ（幅・高さ）を配信画面のレイアウトに合わせて調整し、「OK」をクリックします。

### 外部から操作する場合

Webブラウザから以下にアクセスします。
```
https://natukin1978.github.io/workout-overlay/
```

💡ヒント💡

OBSの`ドック`にある`カスタムブラウザドック`という機能を使って、
OBSのドックとして扱うのもオススメです。
